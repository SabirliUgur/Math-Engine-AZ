## ✨ Xüsusiyyətlər

### 🔢 Standart və Elmi Kalkulyator
- Əsas riyazi əməllər (+, −, ×, ÷)
- Triqonometriya: `sin`, `cos`, `tan`, `cot`
- Loqarifmlər: `ln`, `log`
- Kökaltı, qüvvətə yüksəltmə, faktorial (n!)
- `π` və `e` sabitləri
- **DEG / RAD** keçid düyməsi
- Klaviatura dəstəyi

### 📐 Həndəsə (Ağıllı Hesablama)
- **Müstəvi fiqurlar:** Dairə, Kvadrat, Düzbucaqlı, Üçbucaq, Trapesiya
- **Fəza fiqurları:** Kub, Silindr, Kürə, Konus
- Ağıllı giriş sistemi (məsələn, üçbucaq üçün 3 fərqli hesablama rejimi)
- Hər hesablamada istifadə olunan riyazi düstur göstərilir

### ✖️ Cəbr və Tənliklər
- Kvadrat tənliklərin həlli (diskriminant + köklər)
- 2 və 3 məchullu xətti tənliklər sistemi (Kramer üsulu)
- Faiz hesablamaları (5 müxtəlif rejim)
- Ədədi və həndəsi silsilələr

### 📈 Riyazi Analiz
- Simbolik törəmə hesablaması
- Müəyyən inteqral (Simpson qaydası)
- İnteraktiv funksiya qrafiki (Canvas)

### 🎲 Ehtimal, Statistika və Matrislər
- Ədədi orta, median, moda, standart kənarlaşma
- Permutasiya P(n, r) və Kombinasiya C(n, r)
- 2×2 və 3×3 matris toplama, çıxma, vurma, determinant

## 🎨 Dizayn
- 🌙 **Tünd tema** (Dark Mode) dəstəyi
- Təmiz və minimalist interfeys
- 📱 **Responsive** — kompüter, planşet və telefon ekranına uyğun
- Hesablama tarixçəsi (sağ panel, localStorage ilə saxlanılır)

## 🚀 İstifadə

1. Bu reponu klonlayın:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Math-Engine-AZ.git
   ```
2. `index.html` faylını brauzerdə açın.

Heç bir quraşdırma və ya server tələb olunmur!
